=== Generator interface ===
usage: generate_mixedcode_benchmark.py [-h] --input_csv INPUT_CSV --out_dir
                                       OUT_DIR [--targets TARGETS]
                                       [--bucket_width BUCKET_WIDTH]
                                       [--bucket_width_overrides BUCKET_WIDTH_OVERRIDES]
                                       [--files_per_type FILES_PER_TYPE]
                                       [--seed SEED] [--no_shuffle_candidates]
                                       [--allow_reuse_across_types]
                                       [--keep_lm_prompt]
                                       [--only_targets ONLY_TARGETS]
                                       [--exclude_used_dir EXCLUDE_USED_DIR]
                                       [--exclude_roles EXCLUDE_ROLES]
                                       [--append] [--type_suffix TYPE_SUFFIX]

Generate 6-function mixed-code benchmark .py files with JSON ground truth.

options:
  -h, --help            show this help message and exit
  --input_csv INPUT_CSV
                        Merged HWC/AGC CSV with idx,code,label
  --out_dir OUT_DIR     Output benchmark root directory
  --targets TARGETS     Comma-separated bucket upper bounds. Default:
                        110,120,...,200
  --bucket_width BUCKET_WIDTH
                        Token bucket width. Default: 10
  --bucket_width_overrides BUCKET_WIDTH_OVERRIDES
                        Per-target bucket-width overrides as TARGET:WIDTH
                        pairs, e.g. '200:11'. Only the listed targets use the
                        override; all others keep --bucket_width. Useful to
                        widen one sparse group without changing the rest.
  --files_per_type FILES_PER_TYPE
                        Number of mixed_code_*.py files per type. 0 = maximum
                        possible.
  --seed SEED           Random seed
  --no_shuffle_candidates
                        Do not shuffle candidate pools
  --allow_reuse_across_types
                        Allow the same source function to appear in multiple
                        type buckets. Normally unnecessary because buckets do
                        not overlap.
  --keep_lm_prompt      Use the LM row's own prompt instead of replacing it
                        with the human prompt. Default uses human prompt for
                        AGC body.
  --only_targets ONLY_TARGETS
                        Regenerate only these bucket upper bounds (must be a
                        subset of --targets). Type index and bucket boundaries
                        stay identical to a full run, e.g. --only_targets 200
                        regenerates type10_200.
  --exclude_used_dir EXCLUDE_USED_DIR
                        Scan this existing benchmark tree
                        (type*/mixed_code_*.json) and avoid re-selecting the
                        same source functions, so regenerated files get fresh
                        code. Usually the same path as --out_dir.
  --exclude_roles EXCLUDE_ROLES
                        Comma-separated roles to treat as already-used when
                        --exclude_used_dir is set. Default: AGC (only avoid
                        reusing AGC functions). Pass 'AGC,HWC' to make every
                        function fresh.
  --append              Preserve existing mixed_code_*.py files and continue
                        numbering after the highest existing id per type dir,
                        instead of starting at 001 (which would overwrite
                        existing files).
  --type_suffix TYPE_SUFFIX
                        Append a suffix to the type folder name so regenerated
                        files go into a fresh directory instead of an existing
                        one, e.g. --type_suffix new1 writes type10_200_new1/.
                        Numbering starts at 001 in the new folder and
                        benchmark_type is labeled accordingly.
